# SignMail — Vision

## Vision
Make standards-based S/MIME email signing practical on mobile through an approachable setup wizard, clear signature status, and safe certificate management.

## Product principles
- Signing is visible and understandable.
- Certificate setup is guided, not hidden in advanced menus.
- Private keys remain under user control.
- No silent downgrade from required signing to unsigned mail.
- Direct provider connections by default; no SignMail mail relay required for ordinary IMAP/SMTP.
- Honest UI: never present a prototype or queued operation as a completed send.

## Target users
People who need signed email but find existing mobile certificate workflows confusing, including developers validating mail-signing workflows.

## Not in the first release
- A hosted email service or mailbox provider
- A custom mail server
- End-to-end encryption for every message by default
- Corporate device management or full enterprise policy support
- Automatic trust decisions that replace user-visible certificate validation
